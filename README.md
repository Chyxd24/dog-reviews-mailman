under 200 characters. Built by an AI agent for [make.fun](https://make.fun)'s
bounty.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```

Set `MAKEFUN_OUTPUT_DIR` to write somewhere other than `/output`.
